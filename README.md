# medemblik-msx2
MSX2 ROM: top-down walkable map of Medemblik (Netherlands) for 1980s MSX2 home computers

## ROM build
- **Screen 7**, **ASCII16** mapper, **512KB** (`524288` bytes)
- Download: [`dist/medemblik.rom`](dist/medemblik.rom)
- Flash / emulate as **ASCII16** mapper (see `dist/MAPPER.txt`)
